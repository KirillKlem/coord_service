# GeoRag Coordinate Service

Прототип микросервисного веб-сервиса для геолокации зданий по изображениям в соответствии со спецификацией GeoRag LCT2025. Бэкенд реализован на FastAPI с поддержкой загрузки изображений, инференса (заглушка модели), геокодирования, поиска, экспорта и мониторинга.

## Запуск

```bash
pip install -r requirements.txt
make run-backend
```

Сервис запускается на `http://localhost:8000`. Swagger-документация доступна по адресу `http://localhost:8000/api/openapi.json` и `http://localhost:8000/api/docs`.

## Тесты

```bash
make test
```

## Основные возможности

- Авторизация по JWT (дефолтный администратор `admin` / `admin123`).
- Управление проектами (пространства запросов).
- Загрузка изображений для анализа с синхронной/асинхронной обработкой.
- Заглушка модели, вычисляющая детекции и координаты зданий.
- Офлайн-геокодер с детерминированным адресом.
- Поиск изображений по координатам/адресу.
- Экспорт результатов в XLSX и ZIP.
- Эндпоинты мониторинга: `/system/healthz`, `/system/version`, `/system/metrics`.

## Переменные окружения

| Переменная | Значение по умолчанию | Описание |
| --- | --- | --- |
| `GEORAG_DATABASE_URL` | `sqlite:///./georag.db` | URL базы данных |
| `GEORAG_STORAGE_DIR` | `storage` | Каталог для файлов |
| `GEORAG_SECRET_KEY` | `change-me` | Секрет для JWT |
| `GEORAG_DEFAULT_ADMIN_USERNAME` | `admin` | Логин администратора |
| `GEORAG_DEFAULT_ADMIN_PASSWORD` | `admin123` | Пароль администратора |
| `GEORAG_SYNC_MAX_IMAGES` | `5` | Порог синхронной обработки |
